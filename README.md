# Portfolio Cyber Theme

Portfolio pribadi bertema cyber / Endfield dengan React, TypeScript, Vite, GSAP, dan Tailwind CSS.

**Live site:** [malikfajar.me](https://malikfajar.me)

## Menjalankan secara lokal

```bash
cd app
npm install
npm run dev
```

Build produksi:

```bash
cd app
npm run build
npm run preview
```

## Tech stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- GSAP (ScrollTrigger)
- Lucide React
